# Input and Shortcut Plan

Verified against the active Hyprland Lua files on 2026-09-11; file locations
updated 2026-11-05. Each feature below is a utility in
`~/omarchy-sp10/utilities/<name>/` (see its README); its Hyprland settings are
in `~/.config/hypr/utilities/<name>.lua`.

| Input | Desired behavior | Status | Current configuration |
|---|---|---|---|
| Three-finger drag | Left-click-and-drag for selecting text and dragging files, tabs, and controls | **Done** | `drag_3fg = 1` in `~/.config/hypr/input.lua`. Double-tap-to-drag is off (`tap_and_drag = false`). libinput is a locally patched build (`libinput 1.32.0-1.2`, `~/libinput-sp10/pkg/`): three fingers always drag (never a swipe or pinch), the drag starts immediately, and lifting drops at once. Only a lift at the touchpad's edge (5 mm, like tapping's auto drag-lock) keeps the drag for 300 ms so you can reposition (upstream: every lift waits 700 ms). Takes effect after logging out and back in (Hyprland loads libinput at start) |

Notes:

- `Alt+Tab` shows the switcher even with one window on the desktop. The window tools talk to the shell through `omarchy-shell shell summon rohansguliani.windows '{"cmd":...}'` (about 9 ms). After editing the plugin's QML, run `omarchy restart shell`: Omarchy's hot reload leaves `shell summon` pointing at the old copy, so Alt+Tab and Mission Control stop appearing until a restart.
- `Ctrl+Left` and `Ctrl+Right` are global, so applications do not receive them for word-wise cursor movement.
- `Ctrl+Shift+A` (toggle maximize) and `Ctrl+Shift+1`–`0` (move the window to desktop 1–10 and follow it) are global, set by window-tools (`window-actions/`, `desktops/`). Apps no longer receive them; for example, Helium's tab search (`Ctrl+Shift+A`) is gone.
- The bottom bar auto-hides; touch the bottom edge to show it. It now holds only the Taskbar (left) and the clock (`M/d h:mm AP`, right). The Omarchy menu button, workspace numbers, indicators, world clock, weather, update icon, tray, agents, Bluetooth, network, audio, display and power widgets were removed from the layout in `~/.config/omarchy/shell.json`. Their panels are gone; Bluetooth and Wi-Fi open from Spotlight, audio with `Super+Ctrl+A`; the Omarchy menu is `Super+Space`. Restore the stock layout with `omarchy bar defaults`. The Taskbar plugin (`marcho78.taskbar`, after the workspace numbers) shows the current desktop's windows. Minimized windows show dimmed on every desktop. Click a window to focus it; click the focused one to minimize it; click a dimmed one to restore it to the current desktop. Omarchy's dock (`omarchy.dock`) is disabled; re-enable it with `omarchy plugin enable omarchy.dock`. Hover previews are off (`windowPreviews` false). `Taskbar.qml` has two local patches: `iconCandidates` (icons come from each app's desktop entry, not only its window class) and no width animation. `omarchy plugin update marcho78.taskbar` would overwrite both.
- Maximize on floating desktops (`Ctrl+Shift+A`, titlebar □ and double-click, Helium's tab-row □ and double-click) uses `windowtools.maximize` (`~/.config/omarchy/plugins/rohansguliani.windows/window-actions/window-actions.lua`). It resizes the window to fill the screen instead of using Hyprland's fullscreen state, so opening or Alt+Tabbing to another window no longer un-maximizes it. Plugin README: `~/.config/omarchy/plugins/rohansguliani.windows/README.md`.
- The Surface touchpad has device-specific sensitivity `0.25` (`input.lua`). The MX Master 2S has sensitivity `-0.3` and `scroll_factor = 1.6` (`utilities/logitech-mx-master.lua`).
- MX Master 2S buttons: `~/.local/bin/mx-master` (user service `mx-master.service`, Python, no Solaar) talks HID++ 2.0 to the Unifying receiver to divert the gesture button (CID 0xC3) to Mission Control, re-diverting whenever the mouse reconnects. It also reads the thumb wheel (REL_HWHEEL) and steps desktops (`windowtools.step_desktop`), one per notch with a 0.12 s minimum gap. Access comes from `/etc/udev/rules.d/70-mx-master.rules` (uaccess on the receiver hidraw and the mouse event node). Needs `python-evdev`. Logs every action: `journalctl --user -u mx-master`. Solaar was removed.
- Update this table whenever an input or shortcut is added, changed, or removed.

- Window tools layout (2026-11-04): `~/.config/omarchy/plugins/rohansguliani.windows/` has one folder per tool (`desktops/`, `window-actions/`, `switcher/`, `mission-control/`) plus `shared/`; `load.lua` loads them all from `bindings.lua`. Each tool binds its own keys. See its README.
- Displays page opens without animation (layer rule in `rohansguliani.displays/displays.lua`, loaded from `~/.config/hypr/utilities/displays.lua`). Its tiles show the real resolution and, when scaled, the size it looks like.
