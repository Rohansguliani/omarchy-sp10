# sp10

Microsoft Surface Pro 10 for Business: Intel Core Ultra (Meteor Lake-P,
"Meteor Lake-P [Intel Graphics]"), 2880×1920 120 Hz panel at scale 2, LUKS
root, HP Thunderbolt Dock G4 with a Lenovo T32UD-40 4K at scale 1.5.

- `utilities.txt`: everything, including the three Surface-only utilities.
- `packages.txt`: Intel video decode (Omarchy's installer misses this GPU
  name), microcode, the stock `linux` kernel as a boot fallback.
- `home/.config/hypr/monitors.lua`: written by the Displays page.
- `home/.config/hypr/input.lua`: touchpad settings, Surface touchpad speed.
- `docs/`: detailed notes (`~/omarchySetup` links here).
